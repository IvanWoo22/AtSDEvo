# 高错配敏感性层复核结果

## 结果

32 个高错配事件均被保留在审计明细中，但只有 25 个在双向同坐标 P0 投影后
至少保留 1 个 P0/P/D 均为 A/C/G/T 的可比较位点；其余 7 个事件的精确交集
为 0，不能计算事件级替换率，也没有进入推断统计。25 个可计算事件合计有
5,334 个可比较位点、197 个 P 特异替换和 535 个 D 特异替换，合并计数
D/P=2.716，事件 bootstrap 95% CI 为 1.972–3.597。事件级 D−P rate 的中位数
为 0.05056，bootstrap 95% CI 为 0.00515–0.09366；18 个事件 D>P、3 个
P>D、4 个 tie，双侧 sign test p=0.00149，配对 Wilcoxon p=0.000902。

## 谨慎解释

在仍能形成精确双向 P0 坐标交集的高错配事件中，D 特异替换较多的方向与
44 事件主终点及 55 事件受控集合一致；但这不能视为对主终点的等价重复或
额外样本扩充。高错配层本身由当代 P/D 高分化定义，精确可比较位点急剧减少：
32 个事件中 7 个完全不可计算，而 `>70%` 层仅 7/13 个事件、540 个位点可用，
其 D/P bootstrap CI 跨 1，sign 和 Wilcoxon 均不显著。分层结果也不呈随错配
率单调增强的关系，`(40,50]%` 层只有 1 个事件，不能作群体推断。

因此，较稳妥的表述是：高错配层中“可投影的残余位点”显示 D 偏高信号，但
其方向可能同时受到定位/投影不对称、祖先状态误判、局部同源性丢失和选择性
可计算性的影响。这里的事件 bootstrap 只反映已保留事件之间的抽样变异，
不覆盖这些映射与 P0 重建不确定性。该层应作为独立、探索性的高敏感性结果
报告，不应与 44 事件主终点或 55 事件受控集合合并估计效应或 p 值。
