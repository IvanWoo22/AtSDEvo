# 数据与生成文件管理原则

Git 跟踪源代码、方法文档、小型清单和必要的汇总表，不跟踪以下内容：

- 新下载的基因组组装和注释压缩包；
- BLAST 和 MCScanX 数据库及索引；
- MAFFT、MUSCLE、PRANK 和 IQ-TREE 的逐原子区缓存；
- 完整事件结果树、运行日志和可重建 PDF；
- Python 缓存和本地虚拟环境。

`legacy/benchmark_v1/data/` 中保留了早期 TAIR10/Col-CEN 评测所用的参考文件，
它们不是当前 TAIR12 终点的输入。

需长期保存的大型输入和冻结结果应存入带版本的数据库，并用 SHA-256 清单
记录文件完整性。
