# SD 序列变异流程复核与重整

更新日期：2026-07-25

## 一、复核后的正式分析口径

本轮复核后，不再把 44、51、55 当作三个并列结果，也不再为 time1
建立单独的 indel 分析分支。

- **SNP 主终点：71 个事件。** 使用 P、D、边界 P0 及可用深层 P0 的局部
  多序列比对，只统计三种比对方法一致的局部可比位点。
- **micro-indel 主终点：55 个事件。** time1、time2、time3 位于同一流程，
  仅在结果中按年龄分层。高错配事件的 indel 扩充因 gap 放置不稳定而不采用。
- **原 55 个 SNP 事件：方法学交叉验证集。** 它用于确认“精确双向外群投影”
  与“局部多序列比对”是否给出相同方向，不再作为唯一 SNP 主终点。
- **原 44 和 51 事件：历史敏感性分析。** 不再进入当前摘要、图题或主结论。

不同变异类型使用不同的事件终点并不矛盾。SNP 与 1–10 bp indel 对比对不确定性
的敏感程度不同，应分别定义可检出性，而不是为了表面统一而强制使用同一事件集。

## 二、旧 SNP 流程中“P/D 错配 ≤40%”究竟是什么

旧流程先在 BISER CIGAR 的 `M` 操作中比较当代 P 与 D，只计双方均为大写
ACGT 的位置：

$$
\mathrm{whole\ event\ mismatch} =
\frac{\#(P\ne D)}{\#(P,D\ both\ uppercase\ ACGT)}
$$

该值写入 `present_day_PD_mismatch_pct_callable`。它的作用只是标记或排除
高分化事件，**不是** P/D 定向规则，也不是 SNP 极化依据。旧受控扩充终点
进一步要求：

1. 严格/预设敏感性映射规则通过；
2. P、D 对边界 P0 的双向同坐标投影；
3. `primary_bidir_callable_sites >= 500`；
4. 全事件 P/D mismatch ≤40%。

因此旧流程的瓶颈是“整段事件必须整体相似并且能精确双向投影”，而不是局部
位点本身是否可靠。一个事件只要包含较大的插入/缺失、结构重排或高度分化片段，
就可能因全局错配超过 40% 被整体排除，即使它仍含有数百个可靠局部同源位点。

旧流程中的 SNP 是在精确投影的 P0 坐标上判断：

- P=P0、D≠P0：D 分支特异；
- D=P0、P≠P0：P 分支特异；
- P、D 都与 P0 不同、P0 冲突或非 ACGT：不计。

这个极化逻辑是正确的；需要修改的是事件级全局准入条件，而不是 P/D/P0 的
分支定义。

## 三、重整后的局部多序列比对流程

### 3.1 候选与序列提取

合并严格映射、部分复制后验证和更深 P0 替代队列，并按严格证据优先去重，
得到 116 个非冗余候选事件。对每个事件：

1. 从同源核心恢复 P、D 的基因组坐标和方向；
2. 分别以 P、D 查询边界 P0，取两者查询跨度的并集，避免 P 查询单侧偏倚；
3. 加入可恢复的更深层 P0 序列；
4. 将连续同源区拆为不跨越映射断点的 atomic haplotype。

116 个候选中，81 个事件成功恢复连续 P/D/P0 序列，共 1,418 个 atomic
haplotype。

### 3.2 三比对器一致性

每个 atomic haplotype 独立运行：

- MAFFT v7.526 L-INS-i；
- MUSCLE v5.3；
- 固定物种树、保留插入历史的 PRANK v250331。

一个位点只有在三种比对中同时满足以下条件才进入最终分母：

1. P、D 精确回溯到同一对基因组坐标；
2. 祖先碱基和 P/D 分支类别完全一致；
3. P、D、P0 均为非 soft-mask 的 A/C/G/T；
4. 边界 P0 可用；若更深 P0 可观察但与边界 P0 冲突则排除；
5. 去除 P–D、P0–P 或 P0–D 中长度 ≥11 bp 的 gap run 及两侧 10 bp；
6. 以候选列为中心 ±25 列至少有 20 个 P/D 成对碱基，局部错配率 ≤40%。

最后要求每个事件至少 200 个三比对器一致的 callable sites；500 bp 作为严格
敏感性阈值。这里的“≤40%”已从整段事件过滤改为局部比对质量控制，且大结构
插入/丢失及邻近区段已先被屏蔽。

### 3.3 为什么该流程比直接提高全局阈值更严谨

直接把全事件阈值从 40% 提高到 50% 或 60%，会同时放入可靠保守块和不可判定
的高分化块。局部流程只保留三种算法给出相同坐标、相同祖先碱基和相同分支
极化的列，因此允许“事件可部分比较”，但没有降低到“只要能比上就计数”。

## 五、增加数量后是否仍可靠

### 5.1 对旧 55 事件的独立复核

局部 MSA 71 与旧精确投影 55 共有 54 个事件。两种方法在 51 个非零事件上方向
一致，0 个方向相反，3 个涉及一侧为 tie。旧方法 D/P=2.397，新方法
D/P=2.377。说明结果不是某一种 P0 投影算法的特例。

### 5.2 新救回的 17 个事件

17 个新增事件的全事件 P/D mismatch 均 >40%，但它们仍提供 9,978 个三比对器
一致的局部 callable sites：P=338、D=874，D/P=2.586；16 个事件 D>P，
1 个 P>D。它们提高了事件数与系统发育分层覆盖，但因均来自高全局错配区域，
仍应作为需要重点进行结构变异、基因转换和组装质量审计的亚组。

### 5.3 参数敏感性

- 局部错配上限降至 30%：仍为 71 个事件，P=1,738、D=4,004；
- 大 gap 定义由 ≥11 bp 改为 ≥21 bp：72 个事件，P=1,946、D=4,565；
- 要求至少一个更深 P0 与边界 P0 一致：42 个事件，P=741、D=2,183；
- 主参数下 callable sites 提高到 ≥500：58 个事件，P=1,700、D=4,138。

事件数量和绝对计数随参数变化，但 D>P 的总体方向不变。P/D 双查询 P0 并集
相对原 P-query span 只改变 24 个 callable sites；69/71 个事件方向相同，
其余仅 tie 状态改变，无方向翻转。

## 六、SNP 类型与功能区背景

六类折叠替换（C>A、C>G、C>T、T>A、T>C、T>G）全部为 D>P，说明总体差异
不是由单一替换类型驱动。按各拷贝自身 callable genomic context 计算：

| 区域 | P SNP/callable | D SNP/callable | 有双方分母的事件 | D>P / P>D / tie |
|---|---:|---:|---:|---:|
| CDS | 0.02480 | 0.06675 | 56 | 51 / 3 / 2 |
| non-CDS exon | 0.01874 | 0.04826 | 21 | 9 / 8 / 4 |
| intron/gene body | 0.03680 | 0.07026 | 44 | 26 / 13 / 5 |
| promoter 2 kb | 0.03583 | 0.03725 | 11 | 7 / 3 / 1 |

CDS 中的事件级方向最稳定；其它区域的事件数或成对分母较少，应视为分层描述，
不能据此宣称某一功能区具有确定的速率机制。

## 七、为什么 micro-indel 不同步扩充到 71

micro-indel 的 gap 位置比 SNP 碱基替换更依赖比对。将 116 个候选直接送入
de novo gap 定向后，正式 55 事件为 P=8、D=30；扩充试验变为 P=9、D=104，
其中新增高错配事件为 P=1、D=71。如此单侧的突增主要来自高度分化序列中
alignment-sensitive gap placement，不能作为可信生物学扩增。

因此：

- time1 不单列流程，仍与 time2/time3 统一分析；
- 55 是唯一正式 micro-indel 事件集；
- 71 是唯一正式 SNP 事件集；
- 不把 SNP 可比性自动外推为 indel 可比性。

## 八、当前结论边界与下一步

当前数据支持：在可恢复共同祖先状态的 SD 事件中，D 拷贝积累的分支特异 SNP
多于 P 拷贝，而且该方向在两种祖先比较策略、三个年龄层和多套局部参数下稳定。
这构成 P/D 非对称演化的先决证据，但暂不能直接等同于 D 的绝对中性突变率更高。

进入机制解释前仍需完成：

1. 对 17 个高全局错配救回事件逐事件审计结构变异、基因转换和局部组装质量；
2. 用局部 MSA 71 事件重新计算基因/重复/染色质等协变量，而不沿用旧 55 的
   注释计数；
3. 以事件为独立单位做置换或分层模型，控制年龄、callable length、功能区和
   repeat/mask 构成；
4. 将“变异积累差异”与“突变率差异”“选择强度差异”严格分开表述。
