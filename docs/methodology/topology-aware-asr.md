# 多参考序列与固定拓扑祖先状态重建

## 目的

在现有局部 P/D/P0 MSA 中同时利用所有可获得的参考序列：

- time1：Atha P/D；Alyrata、Bstricta、Dstrictus、Cviolacea P0；
- time2：Atha和Alyrata P/D；Bstricta边界P0及更深P0；
- time3：Atha、Alyrata和Bstricta P/D；Dstrictus边界P0及Cviolacea P0。

实际序列按各事件映射成功情况缺失；不要求所有物种在所有位点均存在。

## 方法

候选位点首先要求：

1. MAFFT、MUSCLE5和固定树PRANK恢复相同P/D基因组坐标；
2. 去除P–D、P–P0、D–P0的大gap及邻近区域；
3. 通过局部P/D错配和uppercase条件；
4. 暂不因深层P0与边界P0冲突而删除，从而交给系统发育模型判断。

随后设置固定复制—物种拓扑。P和D各自形成复制后物种分化支，所有P0按照
从边界到更深外群的顺序包裹复制节点。IQ-TREE3在每个局部原子窗口内优化枝长，
分别用JC和K2P模型计算命名为`DUP`的复制节点祖先碱基。

主ASR规则要求：

- JC和K2P推断相同祖先碱基；
- 两个模型的`DUP`节点后验概率均不低于0.90；
- P、D和祖先碱基据此重新分类，而不是继续固定使用边界P0碱基。

另设不依赖概率模型的直接高置信规则：边界P0至少得到一个更深P0的相同碱基
支持，且所有可观察的更深P0无冲突。

## 解释

多参考序列确实增加了祖先状态信息：

- 深层P0可以识别边界物种自身发生的替换；
- 复制后近缘P/D可以约束P、D分支归属；
- 允许部分物种缺失，避免完整案例过滤再次大量删事件；
- 70事件endpoint没有增加事件数，但增加了约6.4%的可比较位点。

保守的直接多P0规则得到更小但方向更强的35事件集合；概率ASR则在保留70个
事件的同时恢复更多位点。二者均支持D分支积累更多替换。

当前局限是：拓扑固定、枝长按每个短原子窗口估计，ASR仅在PRANK固定树比对上
运行；尚未显式建模ILS、基因转换或不同位点替换模型。因此建议报告为：

1. 原边界P0、无深层冲突：主直接结果；
2. 边界P0＋深层P0一致：保守验证；
3. 固定拓扑双模型ASR：增强型敏感性结果。
