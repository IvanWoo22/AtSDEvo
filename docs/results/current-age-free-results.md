# 当前 age-free P/D 结果

当前主分析采用 GFF 扩展 soft-mask；独立 RepeatMasker 全流程用于检验掩膜敏感性。

## GFF 扩展主分析

| 阶段或端点 | 结果 |
|---|---:|
| BISER calls | 4,734 |
| 非冗余严格二拷贝事件 | 1,655 |
| 9 种设置下 P/D 稳定事件 | 754 |
| 至少恢复 1 个 P0 | 239 |
| SNP 主终点事件 | 195 |
| SNP callable sites | 236,772 |
| P / D 特异 SNP | 9,498 / 15,616 |
| SNP D/P | 1.644 |
| micro-indel P / D | 23 / 54 |
| micro-indel D/P | 2.348 |

SNP 事件中 D>P、P>D 和相等分别为 148、43 和 4，事件 sign test
`p=1.07e-14`；事件 bootstrap 的 D/P 95% CI 为 1.450–1.879。结果支持 D
分支积累更多相对 P0 的派生变化，但不直接等同于原始突变率更高。

## 掩膜敏感性

RM 全流程产生 6,669 个 BISER calls、1,892 个严格二拷贝事件、864 个稳定 P/D
事件、262 个 P0 队列事件和 237 个 SNP 主终点事件。RM SNP 为 P=11,723、
D=19,912，D/P=1.699；事件中 D>P、P>D 和相等分别为 180、50 和 7，sign test
`p=2.03e-18`。

两个掩膜间 RO≥0.50 和 RO≥0.80 的严格事件一对一匹配数分别为 1,272 和 1,131。
RO≥0.50 且两边均进入 age-free P/D 的 585 对事件中，P 位点方向一致率为
585/585。RO≥0.80 且两边均进入 SNP 主终点的 144 对事件中，GFF 与 RM 的 D/P
分别为 1.679 和 1.701，表明 SNP 效应量在同源事件内高度稳定。

RM micro-indel 为 P=20、D=58，D/P=2.900。RO≥0.80 的 175 对可比较事件中，
GFF 与 RM 的 D/P 分别为 1.350 和 2.222。方向仍为 D>P，但效应量明显更受事件
边界、callable 区域和稀疏计数影响。

## 结论边界

- 稳健结论：P/D 极化方向和 SNP 的 D>P 非对称不依赖单一掩膜方案。
- 条件性结论：micro-indel 的方向一致，但精确 D/P 值不是 mask-invariant。
- 不宜合并：不同掩膜产生的全集包含事件替换和边界变化，不能把样本量差异解释为
  生物学事件数的直接增减。
- 当前报告方式：GFF 扩展为主结果，RM 为全流程敏感性分析。

方法与掩膜来源见[RepeatMasker 掩膜敏感性分析](../methodology/repeatmasker-mask-sensitivity.md)。
